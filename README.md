# 🚀 سایت کانفیگ‌های V2Ray

سایت استاتیک (HTML/CSS/JS) که لینک سابسکریپشن V2Ray را می‌خواند و کانفیگ‌ها را
تمیز و مرتب با دکمه کپی نمایش می‌دهد. بدون نیاز به سرور — روی GitHub Pages اجرا می‌شود.

## فایل‌ها

- `index.html` — صفحه اصلی (فارسی، راست‌چین، تم تیره)
- `app.js` — منطق خواندن سابسکریپشن و پارس کانفیگ‌ها (vmess / vless / trojan / ss / ssr / hysteria2 / tuic …)
- `README.md` — همین راهنما

## امکانات

- خواندن خودکار سابسکریپشن (متن ساده یا base64)
- نمایش پروتکل، نام سرور و آدرس هر کانفیگ + دکمه کپی
- جستجو، فیلتر بر اساس پروتکل، دکمه «کپی همه»
- اگر مرورگر به‌خاطر CORS نتوانست لینک را مستقیم بخواند، باکس «چسباندن دستی» نمایش داده می‌شود
- لینک در حافظه مرورگر (localStorage) ذخیره می‌شود

## انتشار روی GitHub Pages

1. یک ریپوی جدید در گیت‌هاب بسازید (مثلاً `v2ray-sub`) — عمومی (Public).
2. هر سه فایل را در ریشه ریپو آپلود/پوش کنید.
3. در گیت‌هاب بروید به **Settings ← Pages** و این‌ها را انتخاب کنید:
   - Source: **Deploy from a branch**
   - Branch: **main** — پوشه: **/ (root)** — بعد **Save**.
4. بعد از یک دقیقه سایت روی این آدرس بالا می‌آید:

   `https://<username>.github.io/<repo>/`

## گذاشتن لینک سابسکریپشن به‌صورت پیش‌فرض

در فایل `index.html` مقدار `DEFAULT_SUB_URL` را با لینک سابسکریپشن پر کنید:

```js
var DEFAULT_SUB_URL = "https://example.com/sub/xxxx";
```

کاربر همچنان می‌تواند از داخل سایت لینک دیگری وارد کند.
